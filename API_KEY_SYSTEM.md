# 🔑 API Key System - User Guide

## 📋 Overview
The English Learning App now uses a **user-provided API key system**. This means:
- ✅ No API keys stored in server files
- ✅ Users enter their own OpenRouter API key
- ✅ Keys are saved permanently in browser (localStorage)
- ✅ Maximum security and privacy

## 🚀 How to Use

### 1. Get Your API Key
1. Visit [OpenRouter.ai](https://openrouter.ai)
2. Create a free account
3. Go to API Keys section
4. Create a new API key
5. Copy the key (starts with `sk-or-v1-`)

### 2. Use AI Teacher
1. Login to the app
2. Click "AI Öğretmen" 
3. Enter your API key when prompted
4. Start chatting with AI teacher!

### 3. Key Features
- 🔒 **Secure**: Keys stored only in your browser
- 💾 **Persistent**: Once entered, works forever (until you clear browser data)
- 🔄 **Changeable**: Use "API Key" button to change anytime
- 👥 **Personal**: Each user uses their own key

## 🛡️ Security Notes
- API keys are stored in browser's localStorage
- Keys are never sent to our servers permanently
- Keys are only used for AI chat requests
- Clear browser data to remove stored keys

## 🆘 Troubleshooting
- **Invalid format error**: Make sure key starts with `sk-or-v1-`
- **401 Unauthorized**: Key might be expired or invalid
- **Key not working**: Try generating a new key from OpenRouter
